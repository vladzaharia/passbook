# Add to Apple Wallet badge

Apple's badge artwork is used without visual changes. The SVG is a preserved copy attributed to Apple at [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Add_to_Apple_Wallet_badge.svg), downloaded 2026-10-30. Apple's current badge download endpoint redirected to its homepage when checked.

The PNG is a proportional rendering of that SVG at 480 px wide for email clients that do not display SVG attachments. The website uses the SVG. Both link directly to the signed pass and retain clear space around the artwork.

Usage guidance: https://developer.apple.com/wallet/add-to-apple-wallet-guidelines/

Apple owns the artwork and trademarks. No ownership of the badge is claimed by this project.
